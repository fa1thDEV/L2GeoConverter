# L2GeoConverter

Инструмент для конвертации, валидации и генерации геодаты Lineage 2 из карт клиента.

Поддерживает форматы Lucera 2 (`.l2g`), Java-эмуляторов (`.l2j`) и официальные бинарные файлы PTS/L2Off (`_conv.dat`).

[Релизы](https://github.com/fa1thDEV/L2GeoConverter/releases/latest) | [Наглядное руководство](docs/GUIDE.md) | [Manual en Español](docs/MANUAL-GEOCONVERTER_ES.md) | [English documentation](README.md)

---

## Возможности

- **Конвертация форматов**: Двустороннее преобразование между `.l2g` (шифрованный формат Lucera 2), `.l2j` (стандартный формат без заголовка, 64k блоков) и PTS `_conv.dat` (послойный формат NCSoft, протоколы `gd` и `286`).
- **Проверка целостности и авто-исправление**: Поиск асимметричных флагов NSWE, опасных обрывов (|ΔZ| > 48, приводящих к провалу под геометрию) и сжатых многослойных блоков с зазором менее 32 единиц. Ключ `--fix` исправляет найденные места и сохраняет пропатченные файлы.
- **Сравнение паков (Diff)**: Поячеечное сравнение двух папок с геодатой (поддержка `.l2j`, `.l2g` и `_conv.dat`). Определение расхождений высот (|Δh| > 16), направлений NSWE и карта несовпадений в формате ASCII.
- **Проверка спавнов (SpawnCheck)**: Сверка координат из `npcpos.txt` с геодатой для поиска мобов, проваливающихся под землю, попадающих в океан или застрявших внутри скал.
- **Сборка из карт клиента**: Парсинг пакетов уровней `.unr` и статических мешей с фильтрами зазора по лучам (raycasting) и ступеней лестниц для предотвращения фантомных потолков и непроходимых подъемов.
- **Компилятор pathnode**: 64-битный многопоточный компилятор файлов `pathnode.bin` и `pathnode.idx` с проверкой прямой видимости (Line-of-Sight).
- **Встроенный веб-просмотрщик**: Локальный HTTP-сервер на порту 8777 для послойного просмотра ячеек, флагов NSWE и 3D-каркасов мешей.
- **Графический интерфейс**: Нативное приложение на Tkinter с вкладками конвертации, диагностики, сборки из UNR, сравнения паков, валидации спавнов и веб-просмотрщика.

## Использование

### Графический интерфейс
Запустите `L2GeoConverter.exe` или выполните `python gui.py`. Откроется окно с выбором файлов для конвертации, диагностики, сборки карт, сравнения паков, проверки спавнов и веб-просмотрщика.

### Командная строка
Вы также можете запускать утилиту напрямую через консоль:

```bash
# Конвертация PTS в L2J
python geotool.py convert path/to/20_20_conv.dat -o ./output -y

# Расшифровка Lucera 2 .l2g в L2J
python geotool.py l2g2l2j path/to/16_20.l2g -o ./output -y

# Шифрование .l2j в Lucera 2 .l2g
python geotool.py l2j2l2g path/to/16_20.l2j -o ./output -y

# Конвертация L2J в PTS (_conv.dat)
python geotool.py l2j2pts path/to/20_20.l2j -o ./output -y

# Проверка геодаты на ошибки
python geotool.py diagnose path/to/geodata/

# Проверка с авто-исправлением
python geotool.py diagnose path/to/geodata/ --fix -o ./repaired/

# Экспорт отчета в JSON
python geotool.py diagnose path/to/geodata/ --json

# Сравнение двух паков геодаты
python geotool.py diff path/to/packA path/to/packB [--region 20_20]

# Проверка спавнов по npcpos.txt
python geotool.py spawncheck path/to/geodata --npcpos path/to/npcpos.txt [-o report.json]

# Запуск веб-просмотрщика
python geotool.py view path/to/geodata/ --port 8777

# Генерация геодаты из клиента игры
python geotool.py generate path/to/client/ -o ./output --region 20_20
```

Для Windows в комплекте идет файл `GeoConverter.bat` для быстрой обработки файлов через Drag-and-Drop.

## Наглядное руководство и механика геодаты

### 1. Направления NSWE и создание невидимых стен

В геодате Lineage 2 каждая ячейка (16x16 игровых единиц) хранит высоту ($Z$) и 4-битовую маску направлений:

| Бит | Флаг | Направление | Hex | Описание |
|---|---|---|---|---|
| бит 0 | `FLAG_EAST` | +X (Восток) | `0x01` | Разрешен шаг на восток |
| бит 1 | `FLAG_WEST` | -X (Запад) | `0x02` | Разрешен шаг на запад |
| бит 2 | `FLAG_SOUTH` | +Y (Юг) | `0x04` | Разрешен шаг на юг |
| бит 3 | `FLAG_NORTH` | -Y (Север) | `0x08` | Разрешен шаг на север |
| биты 0-3 | `FLAG_ALL` | Все | `0x0F` | Полностью проходимая ячейка |
| 0 бит | `FLAG_NONE` | Нет | `0x00` | Непроходимое препятствие / колонна |

<p align="center">
  <img src="docs/images/02_invisible_barriers.png" alt="Флаги NSWE и невидимые барьеры" width="900">
</p>

#### Как создать невидимый барьер
1. **Направленная невидимая стена**: Высота $Z$ обеих ячеек остается одинаковой (например, $Z=100$), но снимаются пограничные флаги:
   - В ячейке A $(gx, gy)$: `nswe &= ~FLAG_EAST` (`0x01`).
   - В ячейке B $(gx+1, gy)$: `nswe &= ~FLAG_WEST` (`0x02`).
   Игрок видит ровную открытую землю, но серверный расчет коллизий блокирует движение через границу.
2. **Сплошная колонна**: Установка флага ячейки в `0x00` (`FLAG_NONE`). В колонну 16x16 нельзя зайти ни с одной из сторон.
3. **Односторонние ловушки (`NSWE_ASYMMETRY`)**: Если ячейка A разрешает проход на восток, а соседняя ячейка B запрещает шаг обратно на запад, персонаж оказывается в ловушке. Модуль диагностики выявляет такие места; ключ `--fix` закрывает открытую сторону (закрытый флаг никогда не открывается: без исходной коллизии нельзя доказать, что проход реален).

---

### 2. Опасные обрывы и сохранение проходов под арками (фикс Гирана)

<p align="center">
  <img src="docs/images/03_cliff_repair.png" alt="Обрывы и арки" width="900">
</p>

* **Опасные обрывы (`CLIFF_FALL`)**: При перепаде высот между соседними ячейками $|\Delta Z| > 48$ с открытым флагом движения персонажи падают сквозь карту в океан или геометрию. Модуль исправления закрывает флаг падения на верхней ячейке.
* **Сохранение дверных проемов и арок**: В городских арках (Гиран, Дион) ячейка арки многослойна (земля $Z=96$, свод $Z=384$) и граничит с уличной ячейкой ($Z=96$). Примитивные алгоритмы блокировали обе ячейки, замуровывая проход по земле. L2GeoConverter применяет блокировку **строго на верхнем слое в сторону обрыва**, сохраняя 100% проходимость земли под арками.

---

### 3. Структура блоков и вертикальный зазор

<p align="center">
  <img src="docs/images/04_block_types.png" alt="Типы блоков геодаты" width="900">
</p>

* **Тип 0 (Flat)**: Единая высота $Z$ для всех 64 ячеек блока. Занимает всего 2 байта.
* **Тип 1 (Complex)**: 64 независимые ячейки со своими $Z$ и 4-битными NSWE.
* **Тип 2 (Multilayer)**: Переменное число слоев (мосты, замковые ворота, этажи). Между слоями должен быть зазор не менее 32 единиц во избежание застревания персонажей.

## Технические детали

### Формат Lucera 2 (.l2g)
Lucera 2 упаковывает 65 536 блоков L2J потоковым шифром на основе вычитания и XOR с 4-байтовым заголовком:
1. `key = read_u32_le(0) ^ 0x814467AB`
2. В цикле расшифровки текущий ключ обновляется знаковой 8-битной арифметикой: `key = (key - decrypted_byte) & 0xFFFFFFFF`.
3. Контрольная сумма проверяет совпадение остатка с дайджестом заголовка.

### Ограничения
- Генерация геодаты из клиента (`generate`) требует наличия папок `Maps` и `StaticMeshes`. Сложные меши с динамическими коллизиями могут требовать ручной корректировки.
- Для ускорения трассировки лучей при генерации рекомендуется установить Taichi (`pip install taichi`), иначе расчет идет на процессоре.
- Построение pathnode на больших картах требует оперативной памяти. Для многопоточного режима желательно иметь не менее 4 ГБ свободной RAM.

## Сборка из исходников

Требования: Python 3.8+. Ядро использует только стандартную библиотеку; дополнительно:

```bash
pip install -r requirements.txt        # Pillow: масштабирование изображений в GUI (нужен Tkinter)
pip install -r requirements-accel.txt  # Taichi + NumPy: ускорение трассировки в `generate`
```

### Запуск тестов

```bash
pip install -r requirements-dev.txt
python -m pytest -m "not slow"   # быстрый прогон (~20 с)
python -m pytest                 # полный набор, включая тяжёлые тесты на целых регионах
```

Тесты, которым нужен настоящий клиент Lineage 2, пропускаются, если не заданы `L2_CLIENT_DIR` (корень клиента с `Maps/`, `Textures/`, `StaticMeshes/`) и `L2_GEODATA_DIR` (папка геодаты сервера). CI запускает линтер и тесты на Linux и Windows при каждом push.

Сборка standalone-бинарника для Windows:
```bash
pip install pyinstaller
python -m PyInstaller --clean --onefile --name L2GeoConverter --collect-all geolib --add-data "assets;assets" geotool.py
```
